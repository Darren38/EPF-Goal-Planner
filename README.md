# EPF Calculator

A single page planner that estimates how long it takes to reach an EPF savings goal in Malaysia.

**Live:** https://darren38.github.io/EPF-Calculator/

## Features

- Goal presets of RM250k, RM500k, RM1m and RM2m, or any custom target
- Contributions from salary (employee and employer share), a fixed monthly amount, voluntary top ups, or yearly bonus
- Annual salary growth
- Dividend rate options: fixed, historical average, trend line, or replay actual declared rates
- Konvensional and Shariah declared rates
- EPF style year end crediting or monthly compounding
- Year by year breakdown table
- Light and dark mode

## Usage

Open the live link above. Nothing is installed and no data leaves your browser.

To run it offline, download `index.html` and open it in any browser.

## Notes

Figures are estimates based on the inputs you provide. Actual EPF dividends are declared yearly and are not guaranteed. This is not financial advice.
